# 中文专利指标柱状图设计

## 目标

基于现有 `plot.py` 中的原始数值，新增独立的中文制图脚本，生成适合专利文档使用的灰度柱状图。现有英文制图脚本、训练代码和实验数据均保持不变。

## 数据与标注

图中继续使用以下均值和误差，不从截图反推数值：

| 指标 | 均值（%） | 误差（百分点） | 中文标签 |
| --- | ---: | ---: | --- |
| Accuracy | 85.34 | 1.20 | 准确率 |
| Macro-F1 Score | 83.37 | 1.80 | 宏平均F1分数 |
| Cohen's Kappa | 80.47 | 1.50 | 科恩κ系数 |

纵轴名称为“性能指标（%）”，范围保持为 40～100。

## 视觉设计

- 三根柱分别使用深、中、浅三档灰色，均带黑色边框。
- 误差线使用黑色，并保留端帽。
- 仅保留浅灰色横向虚线网格，白色背景，不添加装饰性标题或图例。
- 中文字体按可用性依次选择常见 Windows 中文字体；若未找到可用中文字体，脚本应给出明确警告。
- 布局应避免坐标名称或刻度被裁切。

## 输出与兼容性

- 使用 Matplotlib 的非交互后端，使脚本可在无图形界面的环境中运行。
- 同时生成 600 dpi PNG 和可无损缩放的 SVG。
- 输出到脚本旁的稳定目录，文件名明确区分中文专利版本。
- SVG 中的文字转换为路径，以降低在其他计算机上打开时发生中文字体替换的风险。

## 验证

实现后执行以下验证：

1. Python 语法检查。
2. 运行脚本并确认 PNG、SVG 均成功生成。
3. 检查输出文件非空及图像尺寸、PNG 分辨率。
4. 渲染或打开 PNG，目视确认中文无乱码、坐标未裁切、误差线和三档灰度清晰可辨。

- 不修改模型、训练流程和评估协议。
- 不将截图作为新的数据来源。
- 不直接覆盖或涂改原始图片。
